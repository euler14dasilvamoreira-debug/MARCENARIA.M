## Importante
As imagens são carregadas por caminhos relativos, por exemplo `imagens/porta-classica.webp`.
Não coloque as imagens na raiz. Mantenha-as dentro da pasta `imagens`.

## Atualização no GitHub
Substitua `index.html`, `styles.css` e `dados.js` na raiz e adicione `app.js`.

Os nomes das imagens usados agora são exatamente os arquivos que você mostrou na pasta `imagens`. Não apague a pasta `imagens`.

O projeto usa uma nova chave localStorage (`mm_products_v11`) para não reaproveitar os dados antigos com imagens incorporadas em base64.
